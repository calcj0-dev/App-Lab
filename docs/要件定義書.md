## 1. 目的

### 1.1 なぜ作るか（マーケティングマネージャーの方針）
- **全アプリへの入口を1つにする**：X の自己紹介や note のプロフィールに全アプリを載せきれない。まとめサイトのURLを1つ置けば、全アプリに案内できる
- **アプリ同士で人を回す**：どれか1つで来た人に、ほかのアプリも見てもらう。特にゲームから、本命のアプリ「TAMERU」へつなぐ
- **リンク先をそろえる**：note やゲーム投稿サイトの記事から「ほかのアプリはこちら」と同じURLを貼る
- **何を作っている人かを一目で伝える**
- **検索に見つけてもらいやすくする**：まとめサイトから各アプリへリンクする

### 1.2 成功の目安
| 種類 | 指標 | 測り方（8章） |
| --- | --- | --- |
| 主 | まとめサイトから各アプリへ移った数（**特に TAMERU**） | 各アプリの Vercel Analytics の「参照元」に、まとめサイトが何回出たか |
| 副 | まとめサイトの表示数、どこから来たか（X・note など） | まとめサイトの Vercel Analytics |

数値の目標は公開後にオーナーとマーケティングマネージャーで決める。

## 6. 守ること（全アプリ共通のルール）
| ルール | このサイトでの守り方 |
| --- | --- |
| 投資助言と受け取られる表現をしない | お金のアプリ・ゲームは「ツール」「ゲーム」として紹介する。「積立投資を超えろ！」に「ゲームであり、投資助言ではありません。相場は架空です。」を添える。宝くじ100連ガチャ・LIFE & WEALTH・投資キャラ診断にも注意書きを付ける。ページの一番下に「紹介しているツール・ゲームは投資助言ではありません」 |
| 政治的に中立にする | 永田町ポリティクスは「風刺・パロディの政治家カードゲーム」と紹介し、注意書き「風刺・パロディの創作です。実在の人物・政党とは関係ありません。」を添える。**政党名を紹介文に書かない**。画像も特定の政党の人物だけが目立たないものにする |
| シティチェイスの原作ボードゲームの名前を出さない | 紹介文・画像・説明文・ページの中の見えない所（検索用の説明、画像の説明文など）のどこにも書かない。「○○のアプリ版」とも書かない |
| 他のアプリや他人を下げる比較をしない | 「〇〇より便利」などの比較を書かない |
| 確認していない数字を載せない | 利用者数・プレイ数などを載せない。紹介文の数字（「毎月10万円・20年」「1枚300円」「ヘリコプター3機」など）は、各アプリの設計書・プロフィールで確かめたものだけにする |
| 発信者の人物像をそろえる | 「FIREを目指す会社員が、自分で使う道具を作っている」。宣伝の言い方にしない |

## 7. 非機能要件
| 項目 | 要件 |
| --- | --- |
| 端末 | スマホ縦（幅360〜430px）を最優先。PC でも崩れない。X・note のアプリの中のブラウザで開ける |
| 速さ | スマホの回線で、開いてから最初の画面が出るまで2秒以内を目安。最初に読み込むファイルの合計は300KB以下（画像を含む） |
| 検索 | アプリの一覧が、JavaScript を動かさなくても HTML に書かれている（検索エンジンが読めるように） |
| 計測 | まとめサイトは Vercel Analytics（ページの表示）。Cookie を使わない |
| 個人情報 | 取らない。フォーム・ログインなし |
| 更新 | アプリを足す・状態を変えるときは `data\apps.json` を直すだけ。直し方を間違えたら、公開の前に気づける（設計書 9章） |
| 費用 | 無料（Vercel の無料プラン。Vercel Analytics の無料枠は月5万件で、**ほかのアプリと合算**） |

## 8. 計測の考え方（U9）
- Vercel Analytics の無料プランでは、**クリックの記録と UTM の集計は見られない**。データは1か月分だけ残る（[Vercel の料金表](https://vercel.com/docs/analytics/limits-and-pricing)、2026-11-11 確認）
- そこで、主の指標（まとめサイトから各アプリへ移った数）は、**各アプリの Vercel Analytics の「参照元」**で数える。公開中の4つは、どれも Vercel Analytics が入っていることをリポジトリで確かめた（2026-11-11）
- 1か月で消えるので、**月に1回、各アプリの参照元の数を記録に残す**（マーケティングの `log.md`。設計書 7.3）
- UTM は付ける。今は Vercel では見られないが、各アプリが GA4 を使う場合や、将来プランを変えた場合に役立つ
